SEC 提出加密資產保管新規：投資顧問在找不到合格保管機構時，可以自己保管

  • 10 月 1 日，美國 SEC 公布投資顧問與受監管基金保管加密資產的新框架提案，目標是替機構投資人提供一條「合規路徑」，改寫一套大多早於網際網路時代的保管規則。
  • 重點有二：一是在沒有合格保管機構可用的有限情況下，投資顧問可自行保管客戶與基金的加密資產；二是明確允許州立信託公司擔任加密資產保管人。提案公開徵詢意見 60 天。
  • 主委 Paul Atkins 說，加密資產已從「小眾好奇」成長為數兆美元的資產類別；委員 Hester Peirce 則強調，監理機關應「積極保護投資人自行保管的權利」。
  • 這是 Clarity Act 在參院倒下後，SEC 與 CFTC 加速自行訂規的又一步，補上機構直接持有加密資產（而非只透過 ETF）時的保管缺口。

付錢給 AI 不必露臉：以太坊基金會推出 zkAPI，用零知識證明匿名支付模型呼叫費

  • 10 月 1 日，以太坊基金會與開源 AI 隱私計畫 Open Anonymity Project 推出 zkAPI，讓用戶支付 AI 模型等計量型 API 費用時不必揭露身分，已在以太坊主網上線。
  • 運作方式：用戶把 ETH 或 USDC 存入金庫合約，裝置產生零知識證明，證明「有足額資金」但不透露是哪一筆存款；伺服器據此核發有額度上限的臨時 API 金鑰，並以「nullifier」序號防止重複花用。
  • 設計出自 Vitalik Buterin 與基金會 dAI 負責人 Davide Crapis 今年 2 月發表的方案；適用 AI 對話與代理、RPC 查詢、圖像影片生成，以及 AI 代理之間的機器對機器支付。
  • 基金會點出問題：今天每次 API 呼叫都連到帳戶與付款方式，每個提示詞都留下紀錄。限制在於系統不提供網路層匿名，固定 IP 仍可能被關聯。
